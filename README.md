# Calcolo Parallelo

Questa repository raccoglie le tracce svolte dell'esame di **Calcolo Parallelo 2023/2024**.

## Struttura della repository

- 📂 **elearn** → Contiene gli esercizi svolti presenti sulla piattaforma eLearning.  
- 📂 **esame** → Include tracce generiche d'esame per esercitarsi.  

## Descrizione

Il codice presente è stato sviluppato per affrontare problemi di **programmazione parallela**, utilizzando tecniche come:
- Suddivisione in sottomatrici
- Uso di **thread**
- **OpenMP** per il calcolo parallelo
